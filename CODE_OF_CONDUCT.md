# Code de Conduite

## Notre Engagement

Nous nous engageons à rendre participation à ce projet une expérience respectueuse et inclusive pour tous, quel que soit l'âge, la taille, le handicap, l'origine ethnique, les caractéristiques sexuelles, l'identité ou expression de genre, le niveau d'expérience, l'éducation, le statut socio-économique, la nationalité, l'apparence, la race, la religion ou l'orientation sexuelle.

## Nos Standards

Les comportements attendus contribuent à un environnement positif :

- Utiliser un langage bienveillant et inclusif
- Respecter les points de vue et expériences différents
- Accepter gracieusement la critique constructive
- Se concentrer sur ce qui est le mieux pour la communauté
- Montrer de l'empathie envers les autres membres

Les comportements inacceptables incluent :

- Le harcèlement de toute nature
- Les attaques personnelles ou insultes
- Les commentaires insultants ou discriminatoires
- Le harcèlement public ou privé
- La publication d'informations privées sans consentement
- Toute autre conduite considérée inappropriée dans un cadre professionnel

## Portée

Ce code de conduite s'applique à tous les espaces du projet, y compris les issues, pull requests, discussions, et tout autre lieu de communication. Il s'applique également lorsqu'un individu représente le projet dans des espaces publics.

## Signalement

En cas de comportement inacceptable, contactez-nous à l'adresse : [contact@jobiyax.blog](mailto:contact@jobiyax.blog)

Tous les signalements seront traités de manière confidentielle.

## Application

Les responsables du projet peuvent prendre toute action qu'ils jugent appropriée pour répondre aux violations de ce code, notamment :
- Avertissement
- Suppression de contenu
- Exclusion temporaire ou permanente du projet

## Attribution
