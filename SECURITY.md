# Politique de Sécurité

## Versions Supportées

| Version | Supportée          |
| ------- | ------------------ |
| 0.1.x   | Oui                |

## Signaler une Vulnérabilité

Utilisez [GitHub Security Advisories](https://github.com/jobiyax/ecc-cbc-crypto/security/advisories/new) pour signaler privatim les failles de sécurité.

**N'ouvrez pas** d'issue publique pour les vulnérabilités de sécurité.

## Délai de Réponse

- **Accusé de réception** : dans les 48 heures
- **Évaluation initiale** : dans les 7 jours
- **Correction ou mitigation** : selon la sévérité

## Politique de Divulgation

- Nous demandons une divulgation responsable : ne pas rendre publique la faille tant qu'un correctif n'est pas disponible.
- Les signaleurs seront credités dans les notes de version, sauf demande d'anonymat.
