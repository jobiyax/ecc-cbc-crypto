# Politique de Sécurité

## Versions Supportées

| Version | Supportée |
| ------- | --------- |
| 0.1.x   | Oui       |

## Signaler une Vulnérabilité

Utilisez [GitHub Security Advisories](https://github.com/jobiyax/ecc-cbc-crypto/security/advisories/new) pour signaler les failles de sécurité.

**N'ouvrez pas** d'issue publique pour les vulnérabilités.

## Divulgation

Divulgation responsable et signaleurs crédités dans les notes de version.
